- Научиться хранить данные в памяти сервера;

  терминала.

## Краткая теория (вводная часть)

В прошлой работе мы писали все маршруты прямо в **Program.cs**. Это удобно для
маленьких проектов, но когда маршрутов становится 20–30, файл превращается в
кашу. Контроллеры решают эту проблему: каждая группа маршрутов живёт в
отдельном классе. Сервер игр — в **GamesController**, сервер пользователей — в
**UsersController** и т.д.
